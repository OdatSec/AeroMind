\section{Reviewer concern}
\small\itshape ``The attack is demonstrated on an extremely simple initial memory\ldots it's unclear whether the
attack would be successful with different initial memory states\ldots claiming that success doesn't change much from
6 to 200 records is misleading without specifying what those records are.''

\section{Conclusion (what the evidence shows)}
\normalsize\textbf{Retrieval contamination depends on \emph{relative relevance ranking} — not raw memory size — for top-k occupancy.}
\begin{itemize}\itemsep1pt\topsep1pt
\item Raw memory \textbf{size} did not matter for the tested \textbf{off-topic} profiles (3/60/200 records $\to$ CCR 1.0).
\item \textbf{On-topic} benign content \textbf{evicts} the generic poison (CCR $\to$ 0).
\item A \textbf{higher-ranking benign record evicts the poison} — confirmed \emph{causally} (stronger-competitor intervention).
\item Sufficiently query-aligned poison \emph{may} regain top-k, but this is \textbf{template-dependent and fragile, NOT generally robust}.
\end{itemize}
We \textbf{revise — not ``refute''} — the reviewer: composition matters; the concern is partly correct.

\section{Deterministic-retrieval (score audit; score = 0.6\,sim + 0.2\,recency + 0.2\,importance)}
\small The \textbf{poison score is fixed} (0.8171 generic / 0.8921 adaptive); recency$\approx$1.0 and importance$=$0.9 are
constant, so only \textbf{sim} moves the margin. Off-topic distractors score $\le$0.76 $\to$ poison wins by +0.05–0.07;
on-topic benign 0.88 $>$ generic 0.817 $\to$ evicts; adaptive 0.892 squeaks past by +0.004–0.010.
Tie-break: stable sort on 4-decimal score; equal scores keep candidate order.

\section{Scope / limitations}
\small A01/S01 and RET only (isolates memory composition; orthogonal to the threat-model work). Off-topic ``size'' =
3 discrete profiles (no MEM1000); one on-topic template; local deterministic embedder. CCR = observed values;
binary ``poison present in top-k'' = exact Clopper-Pearson 95\% CIs.
